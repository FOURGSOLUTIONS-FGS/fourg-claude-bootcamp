Quickstart v1.1 · Windows
fourgsolutions.com
  1. Crear cuenta de Anthropic Gratis en console.anthropic.com o claude.ai. La vas a usar al final.
  2. Abrir PowerShell como Administrador Tecla Windows → escribir "powershell" → click derecho → "Ejecutar como administrador".
  3. Pegar y dar Enter irm https://raw.githubusercontent.com/FOURGSOLUTIONS-FGS/fourg-claude-bootcamp/main/bootstrap.ps1 | iex (O escaneá el QR de la derecha y pega lo que te muestra)
  4. Responder las preguntas Ruta del workspace · tu nombre · empresa · email · si querés VS Code · si querés IaC.
  5. Esperar ~5 min Instala Node, Python, Git, VS Code, Claude Code. Al final abre el navegador para login.
  6. Cerrar y reabrir PowerShell Para que el PATH se refresque. Después: cd C:\TRABAJOS claude
Modo Express — sin preguntas, todo defaults: & ([scriptblock]::Create((irm https://raw.githubusercontent.com/FOURGSOLUTIONS-FGS/fourg-claude-bootcamp/main/bootstrap.ps1))) -Express -UserName "Tu Nombre" -Email "tu@mail.com"
